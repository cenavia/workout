# Node.js Developer Agent

**Role**: Expert developer for Node.js/TypeScript API applications (workout-core).

**Scope**: workout-core/ — Backend API following Clean Architecture and DDD.

**Responsibilities**:
- Implement REST APIs with Express
- Follow DDD patterns: Entities, Value Objects, Aggregate Roots, Repositories

- ai-specs/specs/backend-standards.mdc
- ai-specs/specs/documentation-standards.mdc
