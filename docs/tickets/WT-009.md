**Título:** Implementar endpoint para listar planes de entrenamiento del usuario
**Tipo:** [FEATURE]
**Estimación:** 2h

**Sprint:** Sprint 2

### Descripción

Implementar endpoint que lista todos los planes de entrenamiento del usuario autenticado, con capacidad de filtrar por estado y paginación. El endpoint debe garantizar aislamiento de datos (solo planes del usuario).

### User Story Relacionada

**Como** usuario  
**Quiero** ver todos mis planes de entrenamiento  
**Para** poder seleccionar, editar o ejecutar uno

---

### Criterios de Aceptación

- [ ] Endpoint `GET /api/workouts` implementado
- [ ] Requiere autenticación JWT
- [ ] Solo retorna planes del usuario autenticado (aislamiento)
- [ ] Filtro por estado: activos, completados, pendientes
- [ ] Ordenamiento por fecha de creación (más recientes primero)
- [ ] Paginación con page y limit
- [ ] Respuesta incluye: id, nombre, fecha creación, número de ejercicios, estado
- [ ] Tests implementados

---

### Especificación Técnica

#### Endpoint

| Método | URL | Descripción |
|--------|-----|-------------|
| GET | `/api/workouts` | Listar planes del usuario |

#### Query Parameters

| Parámetro | Tipo | Requerido | Descripción |
|-----------|------|-----------|-------------|
| status | String | No | Filtrar por estado (active, completed, pending) |
| page | Number | No | Número de página (default: 1) |
| limit | Number | No | Resultados por página (default: 10) |

#### Response

```json
{
  "data": [
    {
      "id": "uuid",
      "name": "Rutina Push",
      "created_at": "2026-02-08T10:00:00Z",
      "exercise_count": 5,
      "status": "active"
    }
  ],
  "pagination": {
    "total": 10,
    "page": 1,
    "limit": 10
  }
}
```
