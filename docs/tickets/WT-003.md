## Ticket: WT-003

**Título:** Implementar funcionalidad de cierre de sesión en frontend
**Tipo:** [FEATURE]
**Estimación:** 1h
**Prioridad:** Alta
**Asignado a:** Sin asignar
**Sprint:** Sprint 1

---

### Descripción

Implementar la funcionalidad de cierre de sesión en el frontend que elimina el token JWT del almacenamiento local y redirige al usuario a la pantalla de login. Opcionalmente, se puede implementar un endpoint en el backend para invalidar tokens (blacklist).

### User Story Relacionada

**Como** usuario autenticado  
**Quiero** cerrar sesión de forma segura  
**Para** proteger mi cuenta cuando termine de usar la aplicación

---

### Criterios de Aceptación

- [ ] Botón/opción de logout visible en la interfaz
- [ ] Al hacer logout, se elimina el token del localStorage/sessionStorage
- [ ] Se redirige al usuario a la pantalla de login
- [ ] No se puede acceder a rutas protegidas después del logout
- [ ] El guard de autenticación detecta la ausencia de token
- [ ] Tests implementados
