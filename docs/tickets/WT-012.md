## Ticket: WT-012

**Título:** Implementar endpoint para eliminar plan de entrenamiento
**Tipo:** [FEATURE]
**Estimación:** 1h
**Prioridad:** Alta
**Asignado a:** Sin asignar
**Sprint:** Sprint 2

---

### Descripción

Implementar endpoint que permite eliminar un plan de entrenamiento. Debe validar que el plan pertenezca al usuario autenticado. Se puede implementar soft delete o hard delete según requerimiento.

### User Story Relacionada

**Como** usuario  
**Quiero** eliminar un plan de entrenamiento  
**Para** mantener mi lista organizada y eliminar planes obsoletos

---

### Criterios de Aceptación

- [ ] Endpoint `DELETE /api/workouts/:id` implementado
- [ ] Requiere autenticación JWT
- [ ] Valida que el plan pertenezca al usuario
- [ ] Elimina plan y ejercicios relacionados (cascade)
- [ ] Retorna 204 No Content al eliminar exitosamente
- [ ] Retorna 404 si el plan no existe
- [ ] Retorna 403 si el plan no pertenece al usuario
- [ ] Tests implementados

---

### Especificación Técnica

#### Endpoint

| Método | URL | Descripción |
|--------|-----|-------------|
| DELETE | `/api/workouts/:id` | Eliminar plan de entrenamiento |

#### Response

**204 No Content:** (éxito)

**403 Forbidden:**
```json
{
  "error": "No tienes permiso para eliminar este recurso"
}
```

**404 Not Found:**
```json
{
  "error": "Plan de entrenamiento no encontrado"
}
```
