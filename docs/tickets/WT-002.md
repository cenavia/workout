## Ticket: WT-002

**Título:** Implementar endpoint de inicio de sesión con JWT
**Tipo:** [FEATURE]
**Estimación:** 2h
**Prioridad:** Crítica
**Asignado a:** Sin asignar
**Sprint:** Sprint 1

---

### Descripción

Implementar el endpoint de inicio de sesión que autentica al usuario con email y contraseña, y genera un token JWT que se utilizará para autenticar requests posteriores. El token debe incluir información del usuario (id, email) y tener una expiración configurable.

### User Story Relacionada

**Como** usuario registrado  
**Quiero** iniciar sesión con mis credenciales  
**Para** acceder a mi cuenta y datos de entrenamientos

---

### Criterios de Aceptación

- [ ] Endpoint `POST /api/auth/login` implementado
- [ ] Validación de credenciales (email y contraseña)
- [ ] Verificación de hash de contraseña con bcrypt
- [ ] Generación de JWT token con payload: { user_id, email }
- [ ] Token con expiración de 24 horas (configurable)
- [ ] Respuesta incluye token y datos del usuario
- [ ] Manejo de errores: 401 para credenciales incorrectas
- [ ] Tests unitarios implementados
- [ ] Documentación OpenAPI actualizada

---

### Especificación Técnica

#### Endpoint

| Método | URL | Descripción |
|--------|-----|-------------|
| POST | `/api/auth/login` | Iniciar sesión y obtener JWT |

#### Request Body

```json
{
  "email": "usuario@example.com",
  "password": "password123"
}
```

#### Response

**200 OK:**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "uuid",
    "email": "usuario@example.com",
    "name": "Juan Pérez"
  }
}
```

**401 Unauthorized:**
```json
{
  "error": "Credenciales incorrectas"
}
```

### Requisitos No Funcionales

- **Seguridad:** 
  - JWT firmado con secret key (desde env)
  - No exponer información sensible en errores
  - Rate limiting para prevenir brute force
- **Performance:** 
  - Verificación de contraseña optimizada
  - Respuesta en < 150ms

---

### Notas Adicionales

- Usar librería JWT (jsonwebtoken para Node.js)
- Secret key debe estar en variables de entorno
- Considerar refresh tokens en futuras iteraciones
- El email debe normalizarse antes de buscar usuario
