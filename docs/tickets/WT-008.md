## Ticket: WT-008

**Título:** Implementar endpoint para crear plan de entrenamiento
**Tipo:** [FEATURE]
**Estimación:** 3h
**Prioridad:** Crítica
**Asignado a:** Sin asignar
**Sprint:** Sprint 2

---

### Descripción

Implementar endpoint que permite crear un nuevo plan de entrenamiento con múltiples ejercicios. Cada ejercicio incluye series, repeticiones y peso. El plan se asocia automáticamente al usuario autenticado. Se debe validar que todos los ejercicios existan y usar transacciones para garantizar integridad.

### User Story Relacionada

**Como** usuario  
**Quiero** crear un nuevo plan de entrenamiento con múltiples ejercicios  
**Para** organizar mis rutinas de forma estructurada

---

### Criterios de Aceptación

- [ ] Endpoint `POST /api/workouts` implementado
- [ ] Requiere autenticación JWT
- [ ] Valida que todos los ejercicios existan
- [ ] Crea plan con nombre, descripción y ejercicios
- [ ] Cada ejercicio incluye: exercise_id, sets, reps, weight
- [ ] Plan se asocia automáticamente al user_id del token
- [ ] Usa transacción para garantizar integridad
- [ ] Retorna plan creado con ID
- [ ] Tests implementados

### Especificación Técnica

#### Endpoint

| Método | URL | Descripción |
|--------|-----|-------------|
| POST | `/api/workouts` | Crear nuevo plan de entrenamiento |

#### Request Body

```json
{
  "name": "Rutina Push",
  "description": "Entrenamiento de empuje",
  "exercises": [
    {
      "exercise_id": "uuid",
      "sets": 4,
      "reps": 8,
      "weight": 60
    }
  ]
}
```
