## Ticket: WT-005

**Título:** Crear seeder de ejercicios predefinidos
**Tipo:** [TASK]
**Estimación:** 2h
**Prioridad:** Crítica
**Asignado a:** Sin asignar
**Sprint:** Sprint 1

---

### Descripción

Crear script de seeder que pobla la base de datos con al menos 50 ejercicios predefinidos categorizados por tipo (cardio, fuerza, flexibilidad) y grupo muscular (pecho, espalda, piernas, hombros, brazos, core). El seeder debe ser idempotente (puede ejecutarse múltiples veces sin duplicar datos).

### User Story Relacionada

**Como** administrador del sistema  
**Quiero** que la base de datos se inicialice con ejercicios predefinidos  
**Para** que los usuarios tengan ejercicios disponibles desde el inicio

---

### Criterios de Aceptación

- [ ] Script de seeder ejecutable (comando o script)
- [ ] Mínimo 50 ejercicios predefinidos
- [ ] Cada ejercicio incluye: nombre, descripción, categoría, grupo muscular
- [ ] Categorías: cardio, fuerza, flexibilidad
- [ ] Grupos musculares: pecho, espalda, piernas, hombros, brazos, core
- [ ] Seeder es idempotente (no duplica al ejecutarse múltiples veces)
- [ ] Validación de existencia antes de insertar
- [ ] Datos en formato JSON o SQL

---

