### Descripción

Implementar endpoint backend que recibe mensajes del usuario y los procesa con el agente LangGraph (Workout Coach). El endpoint debe integrarse con el servicio del agente IA, manejar el historial de conversación y retornar respuestas del agente.

### User Story Relacionada

**Como** usuario  
**Quiero** abrir un chat con el agente Workout Coach  
**Para** recibir asistencia personalizada sobre entrenamientos

---

### Criterios de Aceptación

- [ ] Endpoint `POST /api/chat/message` implementado
- [ ] Requiere autenticación JWT
- [ ] Integración con agente LangGraph
- [ ] Manejo de historial de conversación por usuario
- [ ] Retorna respuesta del agente en formato JSON
- [ ] Soporta WebSocket o polling para respuestas en tiempo real

- [ ] Tests implementados

---

### Especificación Técnica

#### Endpoint

| Método | URL | Descripción |
|--------|-----|-------------|
| POST | `/api/chat/message` | Enviar mensaje al agente |

#### Request Body

```json
{
  "message": "Quiero ganar masa muscular",
  "conversation_id": "uuid" // opcional, para continuar conversación
}
```

#### Response

```json
{
  "response": "¡Perfecto! Para hipertrofia, te recomiendo...",
  "conversation_id": "uuid",
  "tools_used": ["create_workout_plan"]
}
```
