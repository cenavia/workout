## Ticket: WT-011

**Título:** Implementar endpoint para actualizar plan de entrenamiento
**Tipo:** [FEATURE]
**Estimación:** 3h
**Prioridad:** Crítica
**Asignado a:** Sin asignar
**Sprint:** Sprint 2

---

### Descripción

Implementar endpoint que permite actualizar un plan de entrenamiento existente. El usuario puede modificar nombre, descripción y ejercicios (agregar, eliminar, modificar). Debe validar propiedad del plan y existencia de nuevos ejercicios.

### User Story Relacionada

**Como** usuario  
**Quiero** modificar un plan de entrenamiento existente  
**Para** ajustar ejercicios, series, repeticiones o pesos según mi progreso

---

### Criterios de Aceptación

- [ ] Endpoint `PUT /api/workouts/:id` implementado
- [ ] Requiere autenticación JWT
- [ ] Valida que el plan pertenezca al usuario
- [ ] Permite actualizar nombre, descripción
- [ ] Permite agregar, eliminar o modificar ejercicios
- [ ] Valida existencia de nuevos ejercicios
- [ ] Usa transacción para garantizar integridad
- [ ] Retorna plan actualizado
- [ ] Tests implementados

---

### Especificación Técnica

#### Endpoint

| Método | URL | Descripción |
|--------|-----|-------------|
| PUT | `/api/workouts/:id` | Actualizar plan |

#### Request Body (parcial, solo campos a modificar)

```json
{
  "name": "Rutina Push Actualizada",
  "description": "Nueva descripción",
  "exercises": [
    {
      "exercise_id": "uuid",
      "sets": 5,
      "reps": 10,
      "weight": 65
    }
  ]
}
```
