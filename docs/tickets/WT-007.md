### Descripción

Implementar endpoint que retorna la información detallada de un ejercicio específico por su ID. Este endpoint es público y no requiere autenticación.

### User Story Relacionada

**Como** usuario  
**Quiero** ver información detallada de un ejercicio específico  
**Para** entender cómo realizarlo correctamente

---

### Criterios de Aceptación

- [ ] Endpoint `GET /api/exercises/:id` implementado
- [ ] Retorna: nombre, descripción completa, categoría, grupo muscular
- [ ] Retorna 404 si el ejercicio no existe
- [ ] Tests implementados

---

### Especificación Técnica

#### Endpoint

| Método | URL | Descripción |
|--------|-----|-------------|
| GET | `/api/exercises/:id` | Obtener detalle de ejercicio |

#### Response

**200 OK:**
```json
{
  "id": "uuid",
  "name": "Press de banca",
  "description": "Ejercicio compuesto para desarrollar pecho, hombros y tríceps...",
  "category": "fuerza",
  "muscle_group": "pecho"
}
```

**404 Not Found:**
```json
{
  "error": "Ejercicio no encontrado"
}
```
