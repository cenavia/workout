## Ticket: WT-010

**Título:** Implementar endpoint para obtener detalle de plan de entrenamiento
**Tipo:** [FEATURE]
**Estimación:** 2h
**Prioridad:** Crítica
**Asignado a:** Sin asignar
**Sprint:** Sprint 2

---

### Descripción

Implementar endpoint que retorna el detalle completo de un plan de entrenamiento específico, incluyendo todos sus ejercicios con series, repeticiones y pesos. Debe validar que el plan pertenezca al usuario autenticado.

### User Story Relacionada

**Como** usuario  
**Quiero** ver los detalles completos de un plan específico  
**Para** revisar los ejercicios, series, repeticiones y pesos configurados

---

### Criterios de Aceptación

- [ ] Endpoint `GET /api/workouts/:id` implementado
- [ ] Requiere autenticación JWT
- [ ] Valida que el plan pertenezca al usuario (retorna 403 si no)
- [ ] Retorna: nombre, descripción, fecha creación, estado
- [ ] Retorna lista de ejercicios con: exercise_id, nombre ejercicio, sets, reps, weight
- [ ] Retorna historial de ejecuciones si existe
- [ ] Retorna 404 si el plan no existe
- [ ] Tests implementados

---

### Especificación Técnica

#### Endpoint

| Método | URL | Descripción |
|--------|-----|-------------|
| GET | `/api/workouts/:id` | Obtener detalle de plan |

#### Response

**200 OK:**
```json
{
  "id": "uuid",
  "name": "Rutina Push",
  "description": "Entrenamiento de empuje",
  "created_at": "2026-02-08T10:00:00Z",
  "status": "active",
  "exercises": [
    {
      "exercise_id": "uuid",
      "exercise_name": "Press de banca",
      "sets": 4,
      "reps": 8,
      "weight": 60
    }
  ],
  "execution_history": []
}
```

**403 Forbidden:**
```json
{
  "error": "No tienes permiso para acceder a este recurso"
}
```

**404 Not Found:**
```json
{
  "error": "Plan de entrenamiento no encontrado"
}
```
