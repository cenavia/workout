### Descripción

Implementar endpoint que lista todos los ejercicios disponibles con capacidad de filtrar por categoría y grupo muscular, buscar por nombre, y paginar resultados. Este endpoint es público (no requiere autenticación) ya que el catálogo de ejercicios es información general.

### User Story Relacionada

**Como** usuario  
**Quiero** ver el catálogo completo de ejercicios disponibles  
**Para** poder seleccionar ejercicios al crear mis rutinas

---

### Criterios de Aceptación

- [ ] Endpoint `GET /api/exercises` implementado
- [ ] Filtro por categoría (cardio, fuerza, flexibilidad)
- [ ] Filtro por grupo muscular (pecho, espalda, piernas, etc.)
- [ ] Búsqueda por nombre (case-insensitive, parcial)
- [ ] Paginación con page y limit
- [ ] Respuesta incluye: id, nombre, descripción, categoría, grupo muscular
- [ ] Respuesta incluye metadatos de paginación (total, page, limit)
- [ ] Tests implementados

---

### Especificación Técnica

#### Endpoint

| Método | URL | Descripción |
|--------|-----|-------------|
| GET | `/api/exercises` | Listar ejercicios con filtros |

#### Query Parameters

| Parámetro | Tipo | Requerido | Descripción |
|-----------|------|-----------|-------------|
| category | String | No | Filtrar por categoría (cardio, fuerza, flexibilidad) |
| muscle_group | String | No | Filtrar por grupo muscular |
| search | String | No | Buscar por nombre (parcial) |
| page | Number | No | Número de página (default: 1) |
| limit | Number | No | Resultados por página (default: 20, max: 100) |

#### Response

```json
{
  "data": [
    {
      "id": "uuid",
      "name": "Press de banca",
      "description": "Ejercicio compuesto...",
      "category": "fuerza",
      "muscle_group": "pecho"
    }
  ],
  "pagination": {
    "total": 50,
    "page": 1,
    "limit": 20,
    "total_pages": 3
  }
}
```
