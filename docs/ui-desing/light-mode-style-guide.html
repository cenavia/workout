18. Accessibility Guidelines

All color combinations must meet WCAG 2.1 AA standards. These are the verified contrast ratios for the light mode palette.

Key Rules

Do
  • Use white text on Primary Blue, Energy Green, and Vibrant Orange backgrounds
  • Use black/dark text on Lime Accent backgrounds
  • Use Neutral-600 (#757575) or darker for secondary text
  • Provide focus indicators with 3px ring on all interactive elements
  • Include aria-labels on icon-only buttons
  • Use semantic HTML elements (nav, main, section, article)
  • Ensure minimum 44x44px touch targets on mobile
Don't
  • Don't use Vibrant Orange for normal-sized text on white backgrounds
  • Don't use Neutral-400 (#BDBDBD) for readable text (only for disabled/placeholder)
  • Don't rely solely on color to convey information (add icons or text)
  • Don't use Warning Amber as a text color on white (low contrast)
  • Don't remove focus outlines without providing an alternative
  • Don't use Lime as a background for text without dark foreground
